ARCHITECTURE
============

Flow:
  Cortex Apps → OTel Agent (DaemonSet) → OTel Collector → Backends
                     ↓                          ↓
                Host Metrics              Prometheus, Tempo, Loki
                Container Logs

Components:
  - OTel Collector: Central processor (2+ replicas, HA)
  - OTel Agent: Node-level collection (DaemonSet)
  - Instrumentation: Auto and manual for apps

Protocols:
  - OTLP gRPC: Port 4317
  - OTLP HTTP: Port 4318
  - Prometheus: Port 8889
  - Internal Metrics: Port 8888

FEATURES
========

Receivers:
  - OTLP (gRPC/HTTP) for application telemetry
  - Prometheus for metrics scraping
  - Kubernetes cluster metrics
  - Host metrics (CPU, memory, disk, network)
  - Container logs from /var/log/pods

Processors:
  - Memory limiter (OOM prevention)
  - Batch processing (performance)
  - Kubernetes attributes (enrichment)
  - Resource detection
  - Span metrics (RED metrics from traces)
  - Tail sampling (intelligent sampling)
  - Attribute filtering (security)

Exporters:
  - Prometheus (metrics)
  - OTLP (traces to Tempo)
  - OTLP HTTP (logs to Loki)
  - Logging (debugging)

Cortex Integration:
  - Master/worker span tracking
  - Task execution tracing
  - RAG retrieval instrumentation
  - Knowledge base metrics
  - Handoff correlation
  - Token usage tracking

DEPLOYMENT
==========

Prerequisites:
  - Kubernetes 1.24+
  - kubectl configured
  - Prometheus Operator (recommended)
  - 2GB+ memory per node

Quick Deploy:
  cd /Users/ryandahlberg/Projects/cortex/deploy/otel
  ./deploy-otel.sh

Validation:
  ./validate-config.sh

Manual Deploy:
  kubectl create namespace cortex-observability
  kubectl create configmap otel-collector-config \
    --from-file=otel-collector-config.yaml \
    -n cortex-observability
  kubectl apply -f otel-collector-deployment.yaml
  kubectl apply -f otel-agent-daemonset.yaml
  kubectl apply -f cortex-instrumentation.yaml

USAGE
=====

For Node.js agents:
  1. Add to package.json:
     @opentelemetry/sdk-node
     @opentelemetry/auto-instrumentations-node

  2. Initialize at startup (see cortex-instrumentation.yaml)

  3. Create spans:
     const { trace } = require('@opentelemetry/api');
     tracer.startActiveSpan('cortex.master.task', (span) => {
       span.setAttribute('cortex.task.id', taskId);
       // work...
       span.end();
     });

For Python agents:
  1. Install: opentelemetry-api, opentelemetry-sdk

  2. Initialize (see cortex-instrumentation.yaml)

  3. Create spans:
     with tracer.start_as_current_span("cortex.worker.execute") as span:
       span.set_attribute("cortex.task.id", task_id)
       # work...

For Bash scripts:
  source /etc/otel/bash-tracing.sh
  otel_exec "git clone repo"

TESTING
=======

Test OTLP endpoint:
  kubectl run test-otel --image=curlimages/curl --rm -it -- \
    curl -X POST http://otel-collector.cortex-observability.svc.cluster.local:4318/v1/traces \
    -H "Content-Type: application/json" \
    -d @test-span.json

View metrics:
  kubectl port-forward -n cortex-observability svc/otel-collector 8888:8888
  curl http://localhost:8888/metrics

Check logs:
  kubectl logs -n cortex-observability -l app.kubernetes.io/name=otel-collector -f

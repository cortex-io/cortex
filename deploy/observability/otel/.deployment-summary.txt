Features:
---------

Receivers:
  - OTLP gRPC (port 4317)
  - OTLP HTTP (port 4318)
  - Prometheus scraping (existing targets)
  - Filelog (/var/log/pods)
  - Kubernetes events

Processors:
  - Memory limiter (400 MiB, prevent OOM)
  - Batch processor (10s timeout, 1000 items)
  - Resource processor (cluster, environment labels)
  - K8s attributes (pod, deployment metadata)
  - Filter (drop health checks)
  - Tail sampling (100% errors, 10% normal)
  - Cortex attributes (cortex.* namespace)

Exporters:
  - Prometheus (port 8889)
  - OTLP/Traces (Jaeger/Tempo)
  - Loki (logs)
  - Logging (debug)

Integration:
  - Prometheus: ServiceMonitor scrapes collector metrics
  - Grafana: Pre-configured dashboard
  - Alertmanager: 6 alerts for collector health
  - Existing monitoring stack (prometheus-values.yaml)

Cortex-Specific:
  - Agent tracing (coordinator → master → worker)
  - LLM call tracking (Claude API, token counting)
  - Task correlation (cortex.task.id)
  - Worker operations tracking
  - RAG retrieval tracing
  - Custom span attributes (cortex.agent.id, cortex.worker.id, etc.)

Deployment Instructions:
------------------------

1. Quick Deploy:
   cd /Users/ryandahlberg/Projects/cortex/deploy/observability/otel
   ./deploy-otel.sh

2. Manual Deploy:
   kubectl create configmap otel-collector-config --from-file=otel-collector-config.yaml -n monitoring
   kubectl apply -f otel-collector-deployment.yaml
   kubectl apply -f servicemonitor-otel.yaml
   kubectl apply -f otel-instrumentation.yaml

3. Verify:
   kubectl get pods -n monitoring -l app=otel-collector
   kubectl logs -n monitoring -l app=otel-collector -f

4. Add Instrumentation:
   - Auto (Python): Add annotation to pod: instrumentation.opentelemetry.io/inject-python: "true"
   - Manual (TypeScript): Use cortex-tracing-config.ts
